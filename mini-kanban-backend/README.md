# Mini Kanban — Backend

Backend API for the **Mini Kanban Board** application, built for the Webbriks technical assessment.

## Tech Stack

- NestJS (TypeScript)
- PostgreSQL
- Prisma

## Related Repositories

- Root project / docs: [mini-kanban](https://github.com/AlEkramHossainAbir/mini-kanban)
- Frontend: [mini-kanban-frontend](https://github.com/AlEkramHossainAbir/mini-kanban-frontend)

## Getting Started

```bash
npm install
npm run start:dev
```

Setup instructions, environment variables, and API documentation will be documented here as the
project is built out.
