# Mini Kanban — Frontend

Frontend for the **Mini Kanban Board** application, built for the Webbriks technical assessment.

## Tech Stack

- [Next.js](https://nextjs.org/)
- React (TypeScript)
- Tailwind CSS

## Related Repositories

- Root project / docs: [mini-kanban](https://github.com/AlEkramHossainAbir/mini-kanban)
- Backend API: [mini-kanban-backend](https://github.com/AlEkramHossainAbir/mini-kanban-backend)

## Getting Started

```bash
npm install
npm run dev
```

Setup instructions, environment variables, and architecture notes will be documented here as the
project is built out.
